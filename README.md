# digital_shadow

Зеркало контракта цифровой тени агроэксперимента.

- `agroexp/contract/soil/CONTRACT_DIGITAL_SHADOW.md` — контракт v1.2.0 (статусы значений и кто их присваивает, проверки, журнал исправлений, исходное значение и связь с документом, паспорт почвы, плоская сводка показателей).
- `agroexp/contract/soil/reference/` — эталоны `shadow.schema.json` и `ontology.ttl`.

Эталон и код — в репозитории cca (`contracts/`, `core/twin/`, `core/soil_lab/`); при расхождении верен cca, этот репозиторий обновляется копированием в том же изменении.
